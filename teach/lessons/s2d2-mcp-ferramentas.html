MCP — o plug-and-play dos agentes

O agente é o cozinheiro. Skills são as receitas (Dia 1). O harness (Cursor, Claude Code…) já traz alguns utensílios na bancada. O MCP (Model Context Protocol) deixa encaixar utensílios novos — por exemplo o Context7, o manual atualizado das bibliotecas. É o segundo bloco do Agent Harness; no Dia 4, tudo roda junto no fluxo Day/Night.

Resultado:
Diferenciar receita (skill) de utensílio (MCP) e usar Context7 no Cursor ou Claude Code.

Duração:
30–45 minutos (conceito + instalação + um teste real).

Pré-requisito:
Semana 1 · Dia 4 (skills). Cursor e/ou Claude Code instalados.

1. Cozinha do agente

Pense no agente como um cozinheiro (uma persona no harness). Ele segue receitas e usa utensílios na bancada.

  • Já na cozinha (do harness): faca, colher, panela — coisas tipo ler arquivo, editar, rodar comando. Vêm com o programa.
  • Utensílios extras (MCP): você encaixa depois — batedeira, balança, manual atualizado. Sem eles, certos pratos ficam improvisados.

O MCP é o jeito plug-and-play de adicionar esses utensílios extras: o mesmo encaixe no Cursor, no Claude Code e em outro harness. Liga o utensílio → o cozinheiro ganha ações novas. Guarda → aquelas ações somem.

Mapa rápido:

cozinheiro + harness ··· MCP ··· utensílio novo ··· docs / API / dados

Fonte: What is MCP? (na docs oficial a ideia é “padrão único”, tipo USB-C).

2. Receita ≠ utensílio

Uma skill é a receita (SKILL.md): o passo a passo do prato. O MCP traz utensílios que o cozinheiro ainda não tinha na mão.

Skill (receita)MCP (utensílio)
É o quê? Como preparar o prato (SKILL.md) Ferramenta extra na bancada
O que muda? O jeito de trabalhar / o fluxo O que o agente consegue fazer agora
Exemplo implement, code-review Context7 (manual de docs), GitHub…

Receita de bolo sem batedeira = dá pra tentar no braço, sai ruim. Batedeira sem receita = máquina ligada, sem saber o prato. Os dois se completam. Revisar skills: Semana 2 · Dia 1.

3. O que o utensílio entrega

Com um servidor MCP ligado, o agente vê ferramentas novas (ações com nome) além das que o harness já tinha. Exemplo do Context7: achar uma biblioteca e ler a documentação dela.

Não precisa decorar o protocolo. Lembre: utensílio na mão = pode usar; utensílio guardado = só memória + o que já vinha no harness.

4. Context7 — o manual atualizado

Modelos “lembram” APIs do passado. Bibliotecas mudam. Resultado comum: código inventado ou velho.

O Context7 é o utensílio MCP que busca documentação atualizada e por versão e entrega ao cozinheiro. Em vez de inventar um comando, ele abre o manual.

  • Sem Context7: improvisa — às vezes acerta, às vezes inventa.
  • Com Context7: consulta o manual e ancora na fonte.

Chave de API grátis em context7.com/dashboard aumenta o limite de uso; o fluxo remoto com chave costuma ser o mais estável.

O que está na mão agora

    Pedido na cozinha

    6. Colocar o Context7 na bancada

    Faça pelo menos um dos dois ambientes. Chave: context7.com/dashboard.

    Cursor

    Opção A — plugin (1 clique, mais fácil):

    1. Abra Open Cursor Settings.
    2. Vá em Plugins.
    3. Clique em Browse Marketplace.
    4. Procure por Context7.
    5. Clique em Add. O MCP já entra junto — sem colar JSON.
    6. Se pedir, use a API key do dashboard.

    Opção B — manual (JSON):

    1. Abra Cursor Settings → Tools & MCP → New MCP Server (ou edite ~/.cursor/mcp.json / .cursor/mcp.json no projeto).
    2. Cole a conexão remota:
    {
  "mcpServers": {
    "context7": {
      "url": "https://mcp.context7.com/mcp",
      "headers": {
        "CONTEXT7_API_KEY": "YOUR_API_KEY"
      }
    }
  }
}

    Troque YOUR_API_KEY pela sua chave. Reinicie o MCP / o Cursor se a lista não atualizar.

    Claude Code

    Opção A — plugin (padrão):

    1. No Claude Code, adicione o marketplace do Context7:
    /plugin marketplace add upstash/context7
    1. Instale o plugin:
    /plugin install context7@context7-marketplace

    Isso traz MCP + skill + agentes/comandos. Fonte: Context7 · Claude Code.

    Sem API key funciona (limite anônimo). Com chave no dashboard, exporte CONTEXT7_API_KEY no ambiente e reinicie o Claude Code.

    Opção B — terminal (alternativa):

    claude mcp add --scope user --header "CONTEXT7_API_KEY: YOUR_API_KEY" --transport http context7 https://mcp.context7.com/mcp

    Ou local (Node 18+ + npx):

    claude mcp add --scope user context7 -- npx -y @upstash/context7-mcp --api-key YOUR_API_KEY

    Depois: peça algo de biblioteca e diga “use Context7”. Confirme que o agente usou o utensílio de docs, não só inventou texto.

    Missão prática

    Rota na bancada

    1. Nenhum MCP: “micro-ondas + faca” (chute confiante).
    2. Só Context7: creme gelado, picos firmes (manual certo).
    3. Só balança: “200 g” + receita errada (esquentar).
    4. Os dois: peso certo + técnica do manual.

    Rota real (Cursor ou Claude Code)

    1. Crie/pegue a API key no dashboard Context7.
    2. Instale o MCP no Cursor ou no Claude Code (comandos acima).
    3. Peça ajuda com uma biblioteca atual e diga “use Context7”.
    4. Confirme na UI que a ferramenta de documentação foi chamada.

    Transpor para o seu harness

    O MCP é a mesma tomada em qualquer cliente de agente — muda só onde você liga. No Claude Code e no Cursor você viu o caminho; no Codex, no Pi ou em outro, procure por “MCP” ou “tools” nas configurações.

    No Day, o utensílio de docs (Context7) corta chute e reescrita: o agente ancora no manual e você revisa menos. No Night, o agente que trabalha sozinho também usa a tomada — sem o manual, ele inventa API no escuro.
