Skills: achar, instalar e usar o pacote do Matt Pocock

Com a API local no ar, o próximo salto é dar receitas prontas ao agente: skills. Hoje: catálogo em skills.sh, instalação local vs global, e o fluxo grill-with-docs → to-tickets → implement → code-review.

← Dia 3 Guia Semana 2 →

Resultado:
Instalar skills e rodar o fluxo Matt Pocock (planejar → tickets → código → review).

Duração:
25–40 minutos.

Pré-requisito:
Semana 1 · Dias 1–3 (API local ajuda no implement).

1. O que é uma Skill?

Uma skill é um pacote curto de instruções (quase sempre um arquivo SKILL.md) que ensina o agente a seguir um fluxo: perguntar certo, quebrar trabalho em tickets, implementar, revisar. Sem skill, o agente improvisa. Com skill, ele segue o mesmo roteiro toda vez.

2. Achar skills em skills.sh

  1. Abra https://skills.sh/ no navegador.
  2. Busque por autor, tema ou nome (ex.: mattpocock, grill-with-docs).
  3. Na página da skill, copie o comando de instalação — ou use o CLI: 
    npx skills find
npx skills find grill --owner mattpocock

Pacote foco desta aula: mattpocock/skills (também no GitHub: mattpocock/skills).

3. Instalar

No terminal, na pasta do projeto (ou em qualquer lugar se for instalação global):

npx skills add mattpocock/skills --skill grill-with-docs
npx skills add mattpocock/skills --skill to-tickets
npx skills add mattpocock/skills --skill implement
npx skills add mattpocock/skills --skill code-review

Ou o pacote inteiro (quando quiser o kit completo):

npx skills add mattpocock/skills --all

Listar o que já está instalado:

npx skills list
npx skills list -g

4. Local (projeto) vs global (usuário)

Local — projeto

Padrão do skills add sem -g. A skill fica neste repositório (pastas tipo .agents/skills/, .claude/skills/, lock em skills-lock.json). Todo o time do projeto vê as mesmas receitas.

Global — usuário

Use -g / --global. A skill fica na sua conta do sistema e aparece em qualquer projeto. Bom para preferências pessoais; ruim se o colega do repo não tiver a mesma skill. 

# projeto (compartilha com o repo)
npx skills add mattpocock/skills --skill implement

# só na sua máquina / todos os projetos
npx skills add mattpocock/skills --skill implement -g

5. Fluxo Matt Pocock (cadeia principal)

Ordem que fecha o ciclo sem pular etapas:

1. grill-with-docs Entrevista dura sobre o plano. Afia vocabulário e decisões; pode gravar glossário/ADRs.
2. to-tickets Quebra o plano em tickets verticais (fatias demosáveis) com dependências claras.
3. implement Constrói o que os tickets pedem (ideal com testes). Neste curso: modelo local.
4. code-review Revisa o diff em dois eixos (padrão do repo + fidelidade ao pedido). Aqui: modelo normal (nuvem).
grill-with-docs

Afiando o plano antes do código

Digite /grill-with-docs e descreva a ideia. O agente pergunta uma coisa por vez até o plano ficar sólido. Só depois vá para tickets.

to-tickets

Plano vira fatias executáveis

Com o plano afiado, /to-tickets gera tickets pequenos e completos (não “só o banco” ou “só a UI”). Cada ticket diz o que bloqueia o próximo.

implement · modelo local

Código com a IA da sua máquina

/implement no ticket escolhido, com o agente apontado para o modelo local (API dos Dias 1–3). Privacidade, custo zero por token, e prática real do que você já sintonizou em TPS.

code-review · modelo normal

Review com modelo mais forte

Depois do código, /code-review com um modelo normal (não local). Dois olhares em paralelo: padrões do repositório e se o resultado bate com o pedido. Local escreve; review “de fora” pega cheiro que o autor local pode deixar passar.

6. Mini-roteiro da aula (ao vivo)

  1. Abrir skills.sh e achar mattpocock/skills.
  2. Instalar as quatro skills no projeto (sem -g).
  3. Rodar /grill-with-docs numa ideia pequena do aluno.
  4. Rodar /to-tickets a partir do plano.
  5. Pegar um ticket e /implement com modelo local.
  6. Fechar com /code-review em modelo normal.

Missão prática

Rota real: instale as quatro skills no projeto, rode grill-with-docs → to-tickets → um implement local → code-review em modelo normal. Rota simulada: descreva (no chat do tutor) a diferença local vs global e a ordem das quatro skills, sem instalar.
